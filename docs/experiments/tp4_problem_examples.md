# TP4 문제/해설 기반 코칭 실험

## 목적

TP4가 고정 힌트가 아니라 문제·정답·해설을 근거로 막힘 원인 선택지와 단계별 힌트를 생성하는지 확인한다.

---

## 예제 1 — 소금물 비율 문제

### 문제

(가) 비커에 소금 37g을 녹여 소금물 148g을 만들었고,  
(나) 비커에 소금 76g을 녹여 소금물 380g을 만들었습니다.

(가) 비커와 (나) 비커의 소금물의 양에 대한 소금의 양의 비율을 각각 소수로 나타내어 보세요.

### 정답

- (가) 0.25
- (나) 0.2

### 해설 근거

소금물의 양에 대한 소금의 양의 비율은 소금의 양을 소금물의 양으로 나누어 구한다.

- (가): 37 ÷ 148 = 0.25
- (나): 76 ÷ 380 = 0.2

---

## 대상 학생

- 학년: 초등 5~6학년
- 세그먼트: 성실하지만 성취가 낮은 학생
- 상황: 문제 풀이 중 어디서부터 해야 할지 몰라 TP4 도움 버튼 클릭

---

## 기대 흐름

| 단계 | 챗봇 역할 | 학생 경험 |
| --- | --- | --- |
| 0 | 문제/해설을 읽고 막힘 원인 선택지 생성 | "내가 뭘 모르는지" 고를 수 있음 |
| 1 | 학생 선택을 원인 ID로 받음 | 직접 긴 문장을 입력하지 않아도 됨 |
| 2 | 선택한 원인에 맞춰 쉬운 설명 제공 | 문제 말이 조금 더 풀어짐 |
| 3 | 해설 기반 힌트 스텝 제공 | 한 번에 정답이 아니라 작은 단계로 풀이 |
| 4 | teach-back 유도 | 학생이 자기 말로 풀이를 확인 |

---

## 모의 대화

### 1차 진입

**학생**: 코치 도움 받기 클릭

**챗봇**:  
어디가 막혔는지 먼저 골라볼까요?

1. 문제 말이 무슨 뜻인지 모르겠어요
2. 무엇을 무엇으로 나누는지 헷갈려요
3. 소수로 계산하는 게 어려워요

### 선택 후

**학생**: 무엇을 무엇으로 나누는지 헷갈려요

**챗봇**:  
좋아요. 이 문제는 전체 소금물 중 소금이 얼마나 있는지 보는 문제예요.

힌트:

1. (가)에서 소금은 37g, 소금물은 148g이에요.
2. 소금의 양을 소금물의 양으로 나누면 비율을 구할 수 있어요.
3. 그래서 (가)는 37 ÷ 148부터 계산해요.

이제 방금 푼 방법을 본인 말로 한 번 설명해볼 수 있어요?

## 관찰 포인트

- 선택지가 문제/해설에 맞는가?
- 학생에게 내부 세그먼트명이 노출되지 않는가?
- 정답을 바로 알려주기보다 해설 기반 힌트로 유도하는가?
- 고학년 학생에게 너무 유치하거나 너무 긴 설명이 아닌가?
- teach-back이 자연스럽게 이어지는가?
