## 검증

```bash
cd frontend
npm install
npm run typecheck
npm run build
npm run dev -- --host 127.0.0.1
xmllint --noout frontend/public/assets/coach-avatar.svg
```

- `npm install`: 통과, 취약점 0개
- `npm run typecheck`: 통과
- `npm run build`: 통과
- `npm run dev -- --host 127.0.0.1`: `http://127.0.0.1:5173/` 응답 확인
- `coach-avatar.svg`: XML 문법 검증 통과, dev 서버에서 `image/svg+xml`로 응답 확인
