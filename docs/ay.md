  # 오답 콘텐츠 진행률                                                                           
  오답_콘텐츠_진행률: int | None
                                                                                                 
  # 값의 의미:                                                                                 
  # None  → 오답 자체가 없음 (다 맞은 학생, 오답 콘텐츠 할당 자체가 없음)
  # 0     → 오답 있는데 오답 콘텐츠를 하나도 안 함 (진짜 불성실)
  # 50    → 오답 콘텐츠 절반 진행
  # 100   → 오답 콘텐츠 전부 완료 (성실)

  왜 null이 0이나 100보다 나은지:
  ┌──────┬─────────────────────────────────────┬───────────────────────────────────────┐
  │  값  │         "다 맞춘 학생" 처리         │                문제점                 │
  ├──────┼─────────────────────────────────────┼───────────────────────────────────────┤
  │ 0    │ 오답 없는데 0% → 불성실로 오판      │ 의도와 반대                           │
  ├──────┼─────────────────────────────────────┼───────────────────────────────────────┤
  │ 100  │ 한 것도 없는데 100% → 성실로 처리됨 │ 결과는 맞지만 "전부 완료"와 구분 불가 │
  ├──────┼─────────────────────────────────────┼───────────────────────────────────────┤
  │ null │ "해당 없음"으로 명확히 구분         │ 가장 정확한 의미 전달                 │
  └──────┴─────────────────────────────────────┴───────────────────────────────────────┘

  세그먼트 판별 로직에서의 처리

  # 성실도 판별 (pseudo code)
  def is_diligent(student) -> bool:
      # 1차 기준: 학습 완료율 70% 이상
      completion_check = student.평균완료율 >= 70

      # 2차 기준: 오답 콘텐츠 진행률
      if student.오답_콘텐츠_진행률 is None:
          # 오답 없음 → 이 기준은 패스 (불이익 없음)
          wrong_content_check = True
      else:
          wrong_content_check = student.오답_콘텐츠_진행률 >= 기준값  # 예: 50 이상?

      return completion_check and wrong_content_check

  이렇게 하면:
  - 다 맞춘 성실한 학생 → 완료율 70%↑ + 오답 None(패스) → 잘함+성실 ✓
  - 다 맞추고 대충 하는 학생 → 완료율 70%↓ + 오답 None(패스) → 잘함+불성실 (완료율로만 판단)
  - 틀렸는데 복습 안 하는 학생 → 완료율 무관 + 오답 진행률 20% → 불성실 가산
