# 프론트 유저 흐름 및 화면 구성

> 목적: 기획자, 디자이너, 개발자가 같은 화면 경험을 떠올릴 수 있도록 AI 학습코치가 학생에게 어떻게 보이고 동작하는지 정리한다.
> 기준 문서: `docs/PRD.md`, `docs/STATE_DESIGN.md`, `docs/ARCHITECTURE_REVIEW.md`, `TODO_FRONTEND.md`

---

## 1. 전체 방향

프론트는 별도의 "챗봇 앱" 화면이 아니라, 스마트올 학습 화면 위에 붙어 있는 **AI 학습코치 레이어**로 구현한다.

학생은 평소처럼 `오늘의 학습` 화면과 학습 화면을 사용한다. AI 코치는 화면 오른쪽 하단에 캐릭터 얼굴로 떠 있고, 상황에 따라 짧은 말풍선 또는 오른쪽 채팅창으로 도움을 제공한다.

```
오늘의 학습 화면
  → AI 코치가 오늘 할 학습을 추천
  → 학생이 과목/태스크 선택
  → 학습 화면 진입
  → 막히면 오른쪽 하단 캐릭터 클릭
  → 오른쪽 채팅창에서 도움 받기
  → 단위 학습 완료 후 다음 학습 추천
  → 하루 학습 종료 시 오답 복습/마무리 안내
```

---

## 2. AI 코치 노출 방식

AI 코치는 모든 화면에서 동일한 캐릭터로 보이되, 화면 상황에 따라 두 가지 형태로 나타난다.

### 2-1. 플로팅 말풍선형

`오늘의 학습` 메인화면이나 단위 학습 완료 직후처럼 짧은 추천이 필요한 순간에 사용한다.

```
오른쪽 하단: 캐릭터 얼굴
캐릭터 위: 둥근 말풍선
말풍선 안: 짧은 안내 문장 + 선택지/CTA
```

적합한 TP:
- TP1 홈화면 진입
- TP2 단위 학습 완료
- TP3 이탈 시도 1차 붙잡기
- TP5 오늘 학습 종료의 짧은 마무리

### 2-2. 오른쪽 채팅창형

학생이 학습 중 도움을 요청하거나, 조금 긴 코칭이 필요한 순간에 사용한다.

```
평소: 오른쪽 하단 캐릭터 얼굴만 표시
학생 클릭: 오른쪽 사이드 채팅창 열림
채팅창 안: 텍스트, 선택지, 이미지 카드, 힌트 카드
```

적합한 TP:
- TP4 학습 중 도움 요청
- TP3 이탈 시도 후 자세한 도움
- TP5 오답 복습 안내가 길어질 때

## 3. 주요 화면

### 3-1. 오늘의 학습 화면

학생이 처음 진입하는 메인 화면이다. 교육과정 커리큘럼상 오늘 하기로 배정된 과목별 태스크 2~4개를 모아 보여준다.

화면 구성:
- 상단: 스마트올 형태의 내비게이션/날짜/오늘의 학습 탭
- 중앙: 오늘 배정된 과목별 학습 카드
- 좌측 또는 카드 영역: 과목 목록 및 현재 선택된 과목
- 오른쪽 하단: AI 코치 캐릭터
- 캐릭터 위: 오늘 할 학습 추천 말풍선

예시:

```
오늘은 수학부터 해볼까?
[수학으로 이동하기]
```

케이스 1 예시:

```
오늘은 짧은 글 하나만 해볼까?
[1분만 읽어보기]
[그림 보고 주인공 마음 골라보기]
```

케이스 2 예시:

```
오늘은 비율 개념부터 차근차근 해볼까요?
[한 문제를 단계별로 같이 풀기]
[어제 틀린 비례식 다시 보기]
```

이 화면에서 학생은 AI 추천 버튼을 눌러도 되고, 기존 과목/태스크 카드를 직접 눌러도 된다.

---

### 3-2. 학습 화면

학생이 실제 문제나 콘텐츠를 푸는 화면이다. 문제 영역이 중심이고, AI 코치는 방해되지 않게 오른쪽 하단에 캐릭터 얼굴만 떠 있다.

화면 구성:
- 중앙/좌측: 문제 지문, 이미지, 보기, 답안 입력 영역
- 오른쪽 하단: AI 코치 캐릭터 얼굴
- 캐릭터 상태: 살짝 움직이는 idle animation으로 도움 가능 상태 표시
- 캐릭터 클릭 시: 오른쪽 채팅창 열림

기본 상태:

```
[문제/학습 콘텐츠 전체 화면]

오른쪽 하단:
AI 코치 캐릭터 얼굴
```

채팅창 열린 상태:

```
┌─────────────────────────────┬──────────────┐
│                             │ AI 채팅창     │
│        문제 / 학습 화면      │              │
│                             │ 어디가 어려워?│
│                             │ [선택지1]     │
│                             │ [선택지2]     │
└─────────────────────────────┴──────────────┘
```

---

### 3-3. 학습 완료/종료 화면

단위 학습 완료 또는 오늘 학습 종료 시점에 사용한다. 별도 큰 화면을 만들기보다 기존 화면 위에 코치 말풍선 또는 채팅창을 띄우는 방향이 MVP에 적합하다.

단위 학습 완료 예시:

```
좋아! 수학 하나 끝냈어.
다음은 국어 1개만 해볼까?

[국어로 이동하기]
[오늘은 여기까지]
```

오늘 학습 종료 예시:

```
오늘 다 맞았어! 완벽해.
[마치기]
```

오답이 남은 경우:

```
틀린 문제 3개 중 1개가 남았어.
3분만 복습하고 끝낼까?

[오답 복습하기]
[오늘은 끝내기]
```

## 4. TP별 유저 경험

| TP | 진입 시점 | 화면 형태 | 학생 경험 |
|----|----------|----------|----------|
| TP1 | 오늘의 학습 화면 진입 | 플로팅 말풍선 | AI가 먼저 오늘 할 학습을 추천한다 |
| TP2 | 단위 학습 완료 | 플로팅 말풍선 | 완료를 칭찬하고 다음 학습을 제안한다 |
| TP3 | 이탈 시도 | 작은 말풍선 → 필요 시 채팅창 | "이 문제만 끝내고 가자"처럼 부담을 줄여 붙잡는다 |
| TP4 | 학습 중 도움 요청 | 오른쪽 채팅창 | 학생이 캐릭터를 눌러 막힘 원인을 선택하고 도움을 받는다 |
| TP5 | 오늘 학습 종료 | 말풍선 또는 채팅창 | 오답 여부에 따라 마무리/복습을 안내한다 |

## 5. 케이스 1 유저 흐름

대상:
- 초등 1~2학년
- 국어 / 짧은 글 읽기
- 못함 + 불성실

흐름:

```
1. 학생이 오늘의 학습 화면에 들어온다.
2. 오른쪽 하단 AI 코치가 말풍선으로 짧은 국어 활동을 추천한다.
3. 학생이 [그림 보고 주인공 마음 골라보기]를 누른다.
4. 국어 학습 화면으로 이동한다.
5. 학생이 글을 읽다가 막힌다.
6. 오른쪽 하단 캐릭터를 누른다.
7. 오른쪽 채팅창이 열린다.
8. AI가 "어디가 어려워?" 대신 쉬운 선택지를 보여준다.
9. 학생이 [글이 너무 길어]를 선택한다.
10. AI가 글을 한 줄씩 나눠 보여준다.
11. 필요하면 이미지 카드로 상황을 설명한다.
12. 주인공 마음 선택지를 좁혀준다.
13. 학생이 맞히면 즉시 칭찬하고 다음 1문제만 제안한다.
```

예상 화면 톤:
- 짧은 문장
- 큰 버튼
- 쉬운 단어
- 선택지 중심
- 이미지 카드 적극 활용

---

## 6. 케이스 2 유저 흐름

대상:
- 초등 5~6학년
- 수학 / 비율·비례식
- 못함 + 성실

흐름:

```
1. 학생이 오늘의 학습 화면에 들어온다.
2. AI 코치가 비율/비례식 약점 보완 학습을 추천한다.
3. 학생이 [한 문제를 단계별로 같이 풀기]를 누른다.
4. 수학 학습 화면으로 이동한다.
5. 학생이 문제를 풀다가 막힌다.
6. 오른쪽 하단 캐릭터를 누른다.
7. 오른쪽 채팅창이 열린다.
8. AI가 막힘 원인 선택지를 제공한다.
9. 학생이 [식을 어떻게 세우는지 모르겠어]를 선택한다.
10. AI가 기준량/비교량 찾기부터 단계별로 안내한다.
11. 힌트 카드로 풀이 단계를 보여준다.
12. 마지막에 학생에게 "네 말로 한번 설명해볼래?"라고 묻는다.
13. 학생 답변이 충분하면 칭찬하고, 부족하면 보완 설명을 덧붙인다.
```

예상 화면 톤:
- 차분한 코치형 말투
- 문제 조건을 함께 확인하는 흐름
- 단계별 힌트 카드
- teach-back 입력 유도

## 7. 기획 확인 포인트

아래 내용이 맞다면 현재 프론트 구조는 기획 의도와 일치한다.

- TP1과 TP2는 전체 채팅창이 아니라 오늘의 학습 화면 위 말풍선형 추천으로 제공한다.
- TP4는 학습 중 오른쪽 하단 캐릭터를 눌렀을 때 오른쪽 채팅창이 열리는 구조로 제공한다.
- TP3는 작은 말풍선으로 먼저 붙잡고, 필요하면 채팅창을 열 수 있다.
- TP5는 짧은 종료 안내면 말풍선으로, 오답 복습 안내가 길어지면 채팅창으로 제공한다.
- 오늘의 학습 화면에서는 AI 추천 버튼과 기존 과목/태스크 카드 클릭을 모두 허용한다.
