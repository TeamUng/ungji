# 시나리오 기대 출력 기준

> 목적: 기획 의도와 실제 LLM 출력의 차이를 비교하기 위한 기준 문서다.
> 문장을 하드코딩하려는 문서가 아니라, 프롬프트·가드레일·내부 구조를 바꿀 때 "기획 의도에서 벗어났는지" 검수하는 기준이다.

관련 파일:

- 자동 평가 기준: `scripts/scenarios/expected_cases.json`
- 시나리오 실행기: `scripts/run_scenarios.py`
- 실행 결과: `scripts/results/scenario_transcript_*.md`, `scripts/results/scenario_eval_*.csv`

---

## 1. 활용 방식

### 문서 기준

팀원이 아래를 합의한다.

- 케이스별 학생 유형과 학년
- TP1~TP5에서 기대하는 역할
- 학생에게 보여도 되는 출력
- 절대 노출되면 안 되는 출력

### 자동 평가 기준

`scripts/scenarios/expected_cases.json`은 이 문서의 핵심 조건을 구조화한 파일이다.
`scripts/run_scenarios.py`는 실제 LLM 출력에 대해 `must_include` / `must_not_include` / 선택지 개수 등을 검사한다.

### 프롬프트 개선 기준

시나리오 transcript에서 금지 표현이 나오면 다음 순서로 고친다.

1. 프롬프트 출력 계약 보강
2. motivator/helper 역할 경계 보강
3. guardrail repair 보강
4. 필요하면 내부 decision/renderer 구조 보강

---

## 2. 공통 금지 출력

학생 화면에는 아래 표현이 노출되면 안 된다.

- 내부 판단: `추천 이유`, `내부 이유`, `reason_for_llm`
- 실행 지시: `학생 반응을 기다린 후`, `실제 출력`, `도구 호출`
- 도구/구조: `send_text`, `send_causes`, `JSON`, `tool`
- 분류명: `저성취`, `고성취`, `불성실`, `세그먼트`, `유형`
- 없는 콘텐츠: 새 문제, 새 예시, 교과서 페이지, 숙제, 미션

TP3에서는 특히 아래가 금지다.

- `첫 식 잡아줄게`
- `어디가 어려워?`
- `같이 풀어줄게`
- 문제풀이 힌트로 바로 진입하는 표현

TP3는 도움 요청이 아니라 프론트 이탈 이벤트이기 때문이다.

## 3. Case 1 - 저성취/성실 고학년

| 항목 | 값 |
|---|---|
| student_id | `upper-low-diligent` |
| 이름 | 서연 |
| 학년 | 6학년 |
| 학생 유형 | 못함+성실 |
| 첫 과목 | 수학 - 비율과 비례식 |
| TP4 문제 | `math_ratio_saltwater_001` |
| 다음 유도 과목 | 국어 - 주장과 근거 파악하기 |

기획 의도:

- 열심히 하지만 개념 이해가 약한 학생이다.
- 어디서 막혔는지 먼저 끌어내고, 쉬운 표현과 단계 힌트로 스스로 사고하게 한다.
- 정답을 바로 던지지 않고 마지막까지 도달하게 돕는다.

### TP1 - 홈 진입

입력:

```json
{
  "student_id": "upper-low-diligent",
  "use_case": "talk",
  "current_touchpoint": "tp1",
  "message": {"type": "init", "content": ""}
}
```

기대:

- 수학 `비율과 비례식`부터 시작하도록 유도
- 어렵지만 차근차근 하면 된다는 안정감 제공
- 새 문제나 새 과제 생성 금지

예시:

```text
서연아, 오늘은 수학 비율과 비례식부터 차근차근 시작해보자.
조금 어려워 보여도 한 단계씩 보면 충분히 할 수 있어.
```

### TP4 - 수학 문제 도움

입력:

```json
{
  "student_id": "upper-low-diligent",
  "use_case": "learning",
  "current_touchpoint": "tp4",
  "message": {"type": "init", "content": "math_ratio_saltwater_001"}
}
```

기대:

- 처음에는 막힌 지점 선택지를 3개 이하로 제시
- 소금물 비율 문제의 현재 문제와 해설만 사용
- `소금 ÷ 소금물`을 학생이 직접 떠올리도록 유도
- 쉬운 표현과 단계 힌트 사용

좋은 선택지 예:

- 문제 말이 어려워요
- 무엇을 나눠야 할지 모르겠어요
- 계산이 어려워요

좋은 흐름 예:

```text
좋아, 핵심은 "소금이 소금물 전체에서 얼마나 차지하나"를 보는 거야.
(가)부터 보면 소금은 37g, 소금물은 148g이야.
먼저 어떤 식을 세우면 좋을까?
```

### TP2 - 수학 완료 후 다음 과목 유도

기대:

- 수학 완료를 인정
- 다음 과목은 국어 `주장과 근거 파악하기`로 유도
- 저성취/성실 학생답게 차근차근 해볼 수 있다는 톤

예시:

```text
서연아, 어려운 수학을 끝까지 해낸 게 정말 좋아.
다음은 국어 주장과 근거 파악하기로 이어가 보자.
문장을 차근차근 나누면 충분히 할 수 있어.
```

### TP3 - 이탈 이벤트

트리거:

- 학생 자연어 입력이 아니라 프론트 이벤트
- 예: 나가기 버튼 클릭, 뒤로가기, 학습 화면 이탈 시도, 일정 시간 무응답

기대:

- 현재 커리큘럼 종료까지 남은 양을 작게 보여준다.
- 문제풀이 도움으로 넘어가지 않는다.
- 한두 문장으로 마저 완료하도록 유도한다.

예시:

```text
서연아, 거의 다 왔어.
2문제만 더 풀면 이 단원이 끝나.
마저 끝내고 편하게 쉬자.
```

### TP5 - 오늘 학습 종료

오답 있음:

```text
서연아, 오늘 어려운 문제도 끝까지 붙잡고 해낸 게 좋아.
마무리 전에 오답 하나만 가볍게 다시 보면 내일 훨씬 편해질 거야.
```

오답 없음:

```text
서연아, 오늘 학습 정말 잘 마쳤어.
특히 어려운 수학을 끝까지 해낸 게 좋아.
이제 편하게 쉬어도 돼.
```

## 4. Case 2 - 고성취/불성실 저학년

| 항목 | 값 |
|---|---|
| student_id | `lower-high-lazy` |
| 이름 | 도윤 |
| 학년 | 2학년 |
| 학생 유형 | 잘함+불성실 |
| 첫 과목 | 국어 - 받침이 있는 낱말 읽기 |
| TP4 문제 | `lower_korean_reading_001` |
| 다음 유도 과목 | 수학 - 한 자리 수 더하기 |

기획 의도:

- 학습 시작 장벽이 높고 쉽게 이탈하는 학생이다.
- 아주 짧고 쉬운 말로 안내한다.
- TP4에서는 3턴 안에 짧고 명확하게 해결한다.
- 매 턴 칭찬과 즉시 성공감을 준다.

### TP1 - 홈 진입

기대:

- 국어부터 시작
- `딱 5문제`, `금방`, `할 수 있어`처럼 부담을 낮춤

예시:

```text
민준아, 국어부터 딱 5문제만 해보자.
받침 찾기라 금방 할 수 있어!
```

### TP4 - 국어 문제 도움

입력:

```json
{
  "student_id": "lower-high-lazy",
  "use_case": "learning",
  "current_touchpoint": "tp4",
  "message": {"type": "init", "content": "lower_korean_reading_001"}
}
```

기대:

- 선택지 3개 이하
- 아주 쉬운 표현
- 3턴 안에 해결
- 계속 칭찬

좋은 선택지 예:

- 받침이 뭔지 모르겠어요
- 어느 낱말을 봐야 할지 모르겠어요
- 그냥 헷갈려요

좋은 흐름 예:

```text
좋아, 잘 골랐어!
받침은 글자 아래에 붙은 소리야.
'책' 아래에는 ㄱ이 있어.
```

### TP2 - 국어 완료 후 수학 유도

예시:

```text
국어 끝! 민준이 멋지다.
이제 수학 5문제만 해보자.
사과 더하기라 금방 끝나!
```

### TP3 - 이탈 이벤트

예시:

```text
민준아, 거의 끝!
2문제만 더 하면 수학 끝이야.
마저 하고 쉬자!
```

### TP5 - 오늘 학습 종료

오답 있음:

```text
민준아, 오늘 진짜 잘했어!
틀린 건 딱 하나만 다시 보면 끝이야.
같이 짧게 보고 쉬자!
```

오답 없음:

```text
민준아, 오늘 국어도 하고 수학도 했네!
정말 잘했어.
이제 쉬어도 좋아!
```
