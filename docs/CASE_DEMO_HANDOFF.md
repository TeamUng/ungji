# 시연 케이스 작업 인계서

> 시연안(`docs/SCENARIO_EXPECTATIONS.md`)에 맞춰 데이터·코드 작업자에게 전달하기 위한 명세서.
> 시연 흐름 자체는 위 문서에서 확정. 본 문서는 그것을 코드로 옮기기 위한 작업 항목만 정리.

---

## 1. 백엔드 협의 필요 (보류)

작업 전 합의 필요한 항목들. 시연 동작은 문서에 정의돼 있으나 구현 형태가 미정.

| # | 항목 | 정해야 하는 것 |
|---|---|---|
| 1 | 뽀롱이 트리거 입력 형식 | 학생이 뽀롱이를 드래그/클릭했을 때 백엔드로 보낼 `message.type` 값 (예: `trigger_help`?) |
| 2 | TP3 발동 조건 | **학습목록 완료 여부 불리언으로 분기**. 미완료 시에만 이탈 시도에 TP3 발동. 완료 후 나가기는 종료 인사로. |
| 3 | TP5 진입 조건 | **학습목록 완료 여부 불리언으로 분기 + 세그먼트 체크**. true이고 잘함+불성실이 아닐 때만 TP5 진입(+ "복습하러 가기" 버튼). 잘함+불성실은 TP5 발동 X — 동기 유지 위해 복습 강요하지 않음. |
| 4 | 종료 인사 멘트 (Case 1 8단계) | 별도 노드/엔드포인트로 빼야 하는지, TP5와 어떻게 구분할지. (잘함+불성실은 TP5 미발동이라 종료 인사가 마무리 발화) |
| 5 | 정답·오답 표시 | 시연에서는 프론트 하드코딩. **실서비스에서는 문제 이미지를 카드로 보여주고 백엔드가 채점 결과를 응답** — 응답 메시지 타입(예: `image_card` + 채점 플래그)·연동 지점 합의 필요. |

> 2번·3번이 같은 불리언을 공유. 이 불리언 도입이 두 분기의 전제가 됨.

## 2. 후속 작업 (위 1번 결정 후)

### 2-1. 그래프·노드 라우팅 (`app/services/graph.py`, `app/services/nodes/*`)

| # | 작업 | 의존 |
|---|---|---|
| a | `학습목록 완료` 불리언을 ChatState 또는 입력 페이로드에 도입 | 1-3 결정 |
| b | TP3 분기 조건 추가: 학습목록 완료 시 TP3 비활성 | 1-2 결정 + a |
| c | TP5 분기 조건 추가: 완료 + 세그먼트(잘함+불성실 제외)일 때만 진입 | 1-3 결정 + a |
| d | 뽀롱이 트리거 처리: 새 message.type 라우팅 → TP4 helper 노드 | 1-1 결정 |
| e | Case 1 종료 인사 노드/멘트 분기 (잘함+불성실 + 학습 완료 시) | 1-4 결정 |
| f | 채점·문제 이미지 응답 (image_card + 정답·오답 플래그) | 1-5 결정 |

### 2-2. 시나리오 러너 (`scripts/run_scenarios.py`)

| # | 작업 | 의존 |
|---|---|---|
| a | 정답/오답 시뮬레이션 입력 (단계별 학생 응답을 정·오답으로 분기) | 1-5 |
| b | 뽀롱이 트리거 액션 입력 지원 | 1-1 |
| c | "복습하러 가기" 버튼 액션 입력 지원 | 1-3 |
| d | Case 1 새 8단계 시나리오 추가 (TP1·TP2·TP3·TP4·종료 인사) | 1-1, 1-2, 1-4 |
| e | Case 2 5단계 시나리오 추가 (TP1·TP4 ×2·TP2·TP5) | 1-3 |

### 2-3. 프롬프트·가드레일

| # | 작업 | 의존 |
|---|---|---|
| a | TP1·TP2 프롬프트에 성준/아연 페르소나 톤 반영 | 없음 (즉시 가능) |
| b | TP4 helper 프롬프트에 "뽀롱이 트리거 진입" 첫 응답 톤 추가 (`어렵니?`) | 1-1 |
| c | 종료 인사 프롬프트 (잘함+불성실 학습 완료 시) — 뽀롱쌤 페르소나 인사 | 1-4 |
| d | TP5 가드: 잘함+불성실에 TP5 멘트 출력 시도하면 차단 | 1-3 |
| e | TP3 가드: 학습목록 완료 후 TP3 멘트 출력 시도하면 차단 | 1-2 |
