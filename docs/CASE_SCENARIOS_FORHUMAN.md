# 시연 플로우 가이드 (사람 읽기용)

> 발표 자리에서 시연 흐름을 빠르게 떠올리고, 청중에게 "왜 이 케이스인가, 챗봇이 어떻게 다르게 반응하는가"를 설명하기 위한 참고 문서.
>
> 두 케이스를 **화면(터치포인트) 단위**로 풀어서 챗봇 발화·선택지·강조 포인트를 정리했다.
>
> | 더 알아보고 싶다면 | 보면 좋은 문서 |
> |------|------|
> | 데이터 구조·테스트 명세 | `docs/CASE_SCENARIOS.md` |
> | 학생 유형 판별 임계값 | `docs/STATE_DESIGN.md` |
> | 기능 요구사항 원본 | `docs/PRD.md` 섹션 2-5 / 2-6 |

---

## 시작하기 전에

### 이 문서의 용도
- 발표·시연 자리에서 **흐름을 슬라이드 옆에 놓고 보는 큐시트**
- UI/디자인 작업자가 화면 단위 흐름을 파악할 때 참고
- 비개발자 이해관계자에게 "이 챗봇이 뭘 하는 거냐"를 설명할 때 인용

### 시연 환경 (전제)
- 태블릿 화면 비율의 웹 챗봇 UI
- 두 케이스는 학생 드롭다운으로 전환 (mock 학생 ID)
- 실제 스마트올 / 실제 학생 데이터 사용하지 않음

---

## 큰 그림 — 두 케이스를 함께 시연하는 이유

같은 "공부를 잘 못 하는 학생"이라도, **무엇이 막혀 있는가**는 다르다.

| | 케이스 1 — 민준 (초2) | 케이스 2 — 서연 (초6) |
|---|---|---|
| 막힌 지점 | **공부를 시작하는 것 자체** 가 어려움 | 시작은 하지만 **개념에서 막힘** |
| 도와줘야 할 핵심 | 진입장벽 낮추기, 즉시 성공 경험 | 단계별 개념 설명, 이해 검증 |
| 챗봇이 제공하는 것 | 짧은 말, 부담 없는 선택지, 그림 카드 | 차분한 진단, 단계별 힌트, teach-back |
| 시연 가치 | "공부 안 하는 아이"를 책상에 앉히는 흐름 | "공부하는데 안 되는 아이"가 막힌 곳을 푸는 흐름 |

→ 이 둘을 함께 보여주면 **"같은 챗봇이지만 학생에 따라 완전히 다르게 반응한다"** 가 한눈에 드러난다.

# 케이스 1 — 학습 시작 자체가 어려운 초등 2학년

## 한 줄로

> 민준이는 공부하기 싫어서 자주 건너뜁니다. 챗봇이 어떻게 1분이라도 책상 앞에 앉게 만드는가.

## 학생 카드

| 항목 | 내용 |
|------|------|
| 이름 | 민준 (가명) |
| 학년 | 초등 2학년 |
| 오늘 과목 | 국어 |
| 단원 | 문단의 짜임 — 근거 찾기 |
| 챗봇이 인지한 상태 | 최근 학습 완료율이 낮고, 글 읽기 활동을 자주 회피 |

> 발표 메모: "회피형", "저성취" 같은 분류명은 학생 화면 + 발표 슬라이드에 **절대 노출하지 않는다.** PRD가 명시한 핵심 원칙.

## 전체 흐름 한눈에

```
[1] 홈화면 진입
     ↓ 챗봇이 먼저 말 걸기 + 부담 낮춘 선택지 4개

[2] "1분만 짧은 글 읽어보기" 선택
     ↓ 학습 화면 진입 (종이컵 글 + 객관식 1문제)

[3] 학생이 답을 못 정하고 머뭇거림
     ↓ 도움 버튼 클릭

[4] 챗봇이 "왜 어려워?"라고 묻지 않고
    막힘 원인을 선택지로 제공

[5] 학생이 원인 선택
     ↓ 챗봇이 그 원인에 맞는 방식으로 도와줌

[6] 학생이 정답 → 즉시 칭찬 + 다음 1문제만 제안
```

---

## [화면 1] 홈화면 — 챗봇이 먼저 말 건다

**챗봇 발화**
> 민준아 안녕! 오늘도 같이 해보자.
>
> 오늘은 국어 한 문제만 가볍게 봐도 충분해.

**선택지 (4개 버튼)**
- 1분만 짧은 글 읽어보기
- 아주 쉬운 문제 1개만 풀기
- 그림 보고 문단 내용 골라보기
- AI가 오늘 할 것 골라주기

**발표 강조 포인트**
- **챗봇이 먼저 말 건다.** 학생이 "공부할까 말까" 망설이는 시간 자체를 없앤다.
- **선택지 4개가 전부 "부담 낮춤" 표현.** "1분만", "1개만", "AI가 골라줌" — 5분짜리 / 10문제짜리 같은 큰 단위가 의도적으로 빠짐.
- **"학습 시작" 같은 정형 버튼이 없다.** 회피 성향 학생에게는 정형화된 학습 진입점이 그 자체로 장벽.
- 학생 이름을 직접 부른다 → 개인화된 인상.

---

## [화면 2] 학습 진입 — 종이컵 글 + 객관식 문제

학생이 "1분만 짧은 글 읽어보기"를 누르면 학습 화면이 뜬다.

**제시 글** (3개 문단, 발췌)
> (가) 종이컵을 만들기 위해서는 여러 가지가 필요합니다. 먼저 종이의 원료가 되는 나무가 필요합니다. 또 물이 필요합니다...
>
> (나) 그러나 처음부터 종이컵이 나쁜 것은 아니었습니다...
>
> (다) 종이컵을 바르게 사용하기 위해서는 어떻게 해야 할까요?...

**문제**
> 위 글에서 종이컵을 만들기 위해서 필요한 것을 고르면?
>
> ① 물과 우유  ② 나무와 물  ③ 종이와 우유  ④ 학교와 우유  ⑤ 학교와 나무

**시연 시 학생 행동 (대본)**
- 학생이 글을 한 번 슥 보고, 답을 못 정해서 머뭇거림.
- 발표자: "이 시점에서 회피형 학생은 보통 아무 답이나 찍거나 그냥 건너뜁니다." → 자연스럽게 도움 버튼 클릭으로 연결.

---

## [화면 3] 도움 요청 — 직접 묻지 않고 선택지로 진단

학생이 도움 버튼 클릭 → 챗봇 메시지 등장.

**챗봇 발화**
> 어디가 어려워? 같이 보자.

**선택지 (4개)**
- 글이 너무 길어
- 어디서 답을 찾아야 할지 모르겠어
- 답이 다 비슷해 보여
- 그냥 하기 싫어

**발표 강조 포인트**
- **챗봇이 "왜 어려워?"라고 직접 묻지 않는다.** 저학년은 자기 막힘을 말로 표현하기 어렵다.
- 선택지 4개가 곧 **막힘 원인을 진단하는 4축**.
- "그냥 하기 싫어"가 선택지에 있다는 것이 핵심. 학생이 솔직하게 누를 수 있는 출구가 있어야 챗봇이 그 다음을 도와줄 수 있다.

---

## [화면 4] 분기 시연 — "어디서 답을 찾아야 할지 모르겠어" (대표)

> 4개 분기 중 챗봇의 차별점이 가장 잘 드러나는 한 분기를 메인으로 시연.

학생이 "어디서 답을 찾아야 할지 모르겠어" 선택 → 챗봇 응답.

**챗봇 발화 (이미지 카드)**

```
┌──────────────────────────────┐
│  [그림: 종이컵 만드는 과정]  │
│                              │
│  종이컵은 나무와 물로 만들어요│
└──────────────────────────────┘
```

**챗봇 발화 (텍스트)**
> (가) 문단에서 답을 찾을 수 있어.

**발표 강조 포인트**
- **정답을 직접 알려주지 않는다.** "정답은 ②번"이 아니라 "(가) 문단을 다시 보세요"로 단서만 강조.
- **이미지 카드 활용 → 저학년 친화적.** 글만으로 설명하지 않는다.
- "(가) 문단" 같은 출처 표시는 학생이 다시 글을 보는 동기를 만든다.

---

## [화면 4의 다른 분기들] (요약)

대표 분기 외 나머지 3개도 시간이 허용되면 짧게 보여줄 수 있다.

| 학생이 선택한 막힘 | 챗봇 대응 |
|----------------|-----------|
| 글이 너무 길어 | (가) 문단만 한 줄씩 끊어 다시 보여줌. "이번엔 (가) 문단만 같이 읽어보자." |
| 답이 다 비슷해 보여 | "이 중에서 두 개만 보고 골라보자." → 정답 후보 2~3개로 좁힌 선택지 제공 |
| 그냥 하기 싫어 | "한 문제만 같이 해볼까? 진짜 한 개만!" — 초소형 목표로 부담 더 낮춤 |

→ 이 표를 슬라이드 한 장으로 보여주면 **"같은 도움 버튼이지만 학생이 어떤 막힘을 말하느냐에 따라 4가지로 분기된다"** 가 한눈에 전달된다.

---

## [화면 5] 정답 → 마무리

학생이 ② 나무와 물 선택 → 챗봇 즉시 응답.

**챗봇 발화**
> 잘했어! 다음 1문제만 가볼까?

**발표 강조 포인트**
- **즉시 칭찬.** 5분 뒤가 아니라 클릭 직후. 회피형 학생에게 즉시 성공 경험은 다음 학습으로 이어지는 가장 강한 트리거.
- **"다음 1문제만"** 으로 단위 유지. 한 번에 5문제·10문제로 늘리지 않는다.

# 케이스 2 — 시작은 하지만 개념에서 막히는 초등 6학년

## 한 줄로

> 서연이는 매일 책상에 앉지만 비율 단원에서 계속 같은 곳에서 막힙니다. 챗봇이 어떻게 막힌 곳을 풀어주는가.

## 학생 카드

| 항목 | 내용 |
|------|------|
| 이름 | 서연 (가명) |
| 학년 | 초등 6학년 |
| 오늘 과목 | 수학 |
| 단원 | 비율과 비례식 |
| 챗봇이 인지한 상태 | 학습 완료율은 높지만 비율 단원 정답률이 낮고 같은 유형에서 반복 오답 |

## 전체 흐름 한눈에

```
[1] 홈화면 진입
     ↓ 챗봇이 환영 + 약점(비율) 인지 + 보정 학습 선택지 4개

[2] "한 문제를 단계별로 같이 풀기" 선택
     ↓ 학습 화면 (소금물 비율 문제)

[3] 학생이 식을 못 세우고 막힘
     ↓ 도움 버튼 클릭

[4] 챗봇이 막힘 원인 선택지 4개 제공

[5] 학생이 "식을 어떻게 세우는지 모르겠어" 선택
     ↓ 챗봇이 단계별 힌트 카드 3단계 제공

[6] 학생이 식 세우고 정답 계산

[7] 챗봇이 teach-back 유도 — "너의 말로 다시 설명해줄래?"
     ↓ 학생 설명 → 칭찬 + 부족한 부분 보완
```

---

## [화면 1] 홈화면 — 약점을 부드럽게 짚어줌

**챗봇 발화**
> 서연아, 오늘도 와줘서 고마워.
>
> 오늘은 비율 부분을 한 번 같이 짚어볼까? 어렵지 않게 단계로 나눠서 보면 돼.

**선택지 (4개)**
- 비율 개념 쉽게 다시 보기
- 어제 틀린 비례식 문제 다시 풀기
- 한 문제를 단계별로 같이 풀기
- 내가 어디서 헷갈렸는지 확인하기

**발표 강조 포인트**
- 케이스 1과 톤이 완전히 다르다. **차분하고 코치형**, 존댓말 혼합.
- "비율"이라는 약점을 **평가 아닌 학습 의도**로 풀어 말함. "못한다"는 표현 없음.
- 선택지 4개 모두 "복습 / 단계별 / 진단" 키워드 → 케이스 1의 "1분만 / 1개만"과 정반대 결.

---

## [화면 2] 학습 진입 — 소금물 비율 문제

학생이 "한 문제를 단계별로 같이 풀기"를 누르면 학습 화면 진입.

**제시 문제**
> (가) 비커에 소금 37g을 녹여 소금물 148g을 만들었습니다.
>
> (나) 비커에 소금 76g을 녹여 소금물 380g을 만들었습니다.
>
> **(가) 비커와 (나) 비커의 소금물의 양에 대한 소금의 양의 비율을 각각 소수로 나타내어 보세요.**

**시연 시 학생 행동 (대본)**
- 학생이 문제를 읽고 식을 세우려다 멈춤.
- 발표자: "여기서 학생이 막히는 건 '계산'이 아니라 **'무엇을 분모로, 무엇을 분자로 둘지'** 입니다."

---

## [화면 3] 도움 요청 — 막힘 원인 진단

**챗봇 발화**
> 어떤 부분이 헷갈렸어? 같이 짚어보자.

**선택지 (4개)**
- 비율 뜻이 헷갈려
- 어떤 수끼리 비교해야 할지 모르겠어
- 식을 어떻게 세우는지 모르겠어
- 계산하다가 틀렸어

**발표 강조 포인트**
- 케이스 1의 4개 선택지(글이 너무 길어, ...)와 **완전히 다른 4개**.
- 같은 챗봇이지만 **과목·학년에 맞춰 막힘 원인이 다르게 정의**되어 있음.
- 4개 중 **"식을 어떻게 세우는지 모르겠어"가 가장 흔한 막힘** — 개념은 들었는데 적용이 안 되는 패턴.

---

## [화면 4] 분기 시연 — "식을 어떻게 세우는지 모르겠어" (대표)

학생이 "식을 어떻게 세우는지 모르겠어" 선택 → 챗봇 응답.

**챗봇 발화 (텍스트)**
> 좋아, 한 단계씩 같이 가볼까?

**챗봇 발화 (단계별 힌트 카드)**

```
┌─────────────────────────────────────────────┐
│  1단계   '에 대한' 앞이 기준량,              │
│          뒤가 비교량이에요                  │
├─────────────────────────────────────────────┤
│  2단계   (가) 비커에서 기준량(소금물)과     │
│          비교량(소금)을 g 단위로 적어보세요 │
├─────────────────────────────────────────────┤
│  3단계   비율 = 비교량 ÷ 기준량 으로        │
│          식을 세우면 돼요                   │
└─────────────────────────────────────────────┘
```

**발표 강조 포인트**
- **정답 수치(0.25, 0.2)는 어디에도 안 나온다.** 학생이 단계를 따라 직접 도달.
- 케이스 1의 이미지 카드 자리에 **단계별 힌트 카드**. UI 요소가 학년·세그먼트에 맞춰 다르다.
- "1단계 → 2단계 → 3단계" 구조 자체가 **개념 부족형 학생에게 필요한 사고 흐름**을 시각화한다.

## [화면 4의 다른 분기들] (요약)

| 학생이 선택한 막힘 | 챗봇 대응 |
|----------------|-----------|
| 비율 뜻이 헷갈려 | 일상 비유로 재설명. "비율은 '전체 중에 얼마'야. 1L 우유에 100mL 시럽을 넣으면 우유가 기준량, 시럽이 비교량인 거지." |
| 어떤 수끼리 비교해야 할지 모르겠어 | "이 문제에서 기준량이 뭘까? 한번 골라볼래?" → 후보 3개 (소금물의 양 / 소금의 양 / 물의 양) 제공 |
| 계산하다가 틀렸어 | 식이 맞은 것은 먼저 칭찬 + 분수 약분 점검 유도. "분수를 약분할 때 어떤 수로 나눴는지 다시 짚어볼까?" |

## [화면 5] 정답 → teach-back

학생이 (가) 0.25, (나) 0.2 도달.

**챗봇 발화**
> 정확해! 그럼 한 가지만 부탁할게.
>
> 방금 푼 걸 너의 말로 다시 한 번 설명해줄 수 있어?

**학생 입력 예시 (시연용 대본)**
> 소금물이 기준이고 그 안에 들어있는 소금이 비교라서, 소금을 소금물로 나누면 비율이 나와.

**챗봇 응답**
> 정확해! 기준량과 비교량을 잘 잡았어. 다음 문제는 분모가 더 복잡한 걸로 가볼까?

**발표 강조 포인트**
- **teach-back은 케이스 2의 차별점.** 정답을 맞히는 것보다 **"왜 그게 답인지를 자기 말로 설명할 수 있는가"** 가 진짜 이해의 척도.
- 챗봇이 학생 설명을 듣고 **부족한 부분만 짚어 보충.** 잘한 부분도 동시에 짚어준다.
- 케이스 1에서는 teach-back을 안 한다 — 저학년에게는 부담이고, 즉시 성공 경험이 더 중요. **케이스에 맞는 코칭 강도를 다르게 선택**하는 것이 핵심.

# 발표 시 강조할 큰 포인트 3가지

## 1. "한 챗봇이 다 다르게 반응한다"

같은 코드, 같은 모델인데 **학생에 따라 톤·UI 요소·코칭 강도가 모두 다르다.** 이게 단순 챗봇이 아니라 "학습 코치"라는 포지셔닝의 핵심.

## 2. "정답을 바로 알려주지 않는다"

- 케이스 1: "(가) 문단에서 찾을 수 있어" — 단서만 제공
- 케이스 2: 단계별 힌트 카드, 정답 수치(0.25 / 0.2) 노출 X

→ 학습용 AI의 정체성. 답을 알려주는 챗봇이라면 그냥 일반 챗봇을 쓰면 된다.

## 3. "학생을 평가하지 않는다"

화면 어디에도 "당신은 저성취 학생입니다", "회피형입니다" 같은 분류 표시가 없다. 학생은 **자신이 분류되었다는 사실 자체를 모른다.** 부드러운 톤으로 자연스럽게 도움.

# 자주 받을 질문 (FAQ)

**Q. 학생 유형은 어떻게 판단하나요?**
A. 최근 7일의 정답률·학습 완료율·오답 콘텐츠 진행률·건너뛰기 빈도를 mock 데이터로 보유하고, 임계값 기준으로 4가지 유형으로 분류합니다. 세션 시작 시 1회 판단하고 그 세션 동안 유지.

**Q. 실제 스마트올과 연동되나요?**
A. MVP는 연동하지 않습니다. 모든 학생/문제는 목업 데이터.

**Q. 정답을 바로 알려달라는 학생이 있으면요?**
A. 정책상 정답 직접 제공은 지양. 단계적 힌트로 유도하되, 학생이 정답을 입력했을 때만 정답으로 확정. 회피형 학생용 안전망 옵션("AI가 풀어주기")은 후속 작업으로 검토 가능.

**Q. 두 케이스만으로 충분한가요?**
A. MVP는 학년·유형의 대비가 명확한 두 케이스만 시연. PRD에 정의된 4개 세그먼트 중 2개를 시연하고, 나머지 2개(잘함+성실, 잘함+불성실)는 후속 작업.

**Q. 케이스 1에 단계별 힌트 카드를 안 쓰는 이유는요?**
A. 저학년 + 불성실 유형은 한 번에 한 행동만 제안하는 것이 효과적. 단계별 카드는 부담을 늘릴 수 있어 의도적으로 배제.

**Q. 케이스 2에 이미지 카드를 안 쓰는 이유는요?**
A. 고학년 + 성실 유형은 텍스트 기반 단계별 사고를 따라갈 수 있고, 그게 더 효과적. 이미지 카드는 저학년의 상황 이해 보조용.

**Q. 학생이 챗봇 답변에 만족 못하면 어떻게 되나요?**
A. 챗봇은 같은 분기 안에서도 매번 다른 표현으로 응답할 수 있도록 LLM이 자연어를 채운다. 또한 "도움이 안 됐어"를 다시 누르면 다른 분기로 재진단 가능.
