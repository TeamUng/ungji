- **`motivator` 노드 (TP1·TP2·TP3·TP5)** → **gpt-5.4-mini**
  근거: 6개 시나리오 중 4개에서 1위(TP1 고학년·TP2·TP4 코칭·TP5). 응답이 가장 짧고 안정적이어서 학년 톤 한도(60~150자)에 가장 가까움. 글자수 σ 69.2로 두 번째로 안정. 환각·메타 노출 0건.
- **`helper` 노드 / TP4 원인선택지** → **solar-pro3** (또는 gemini-2.5-flash)
  근거: 10/10 모두 `send_causes` 도구 호출 성공해 choices 메시지로 안정 출력. 길이 OK 비율 100%. **gpt 계열은 이 경로에서 사용 불가**.
- **`helper` 노드 / TP4 코칭응답** → **gpt-5.4-mini**
  근거: 단계별 hint_card 가장 일관되게 출력. 환각·메타 노출 없음.

**비용 절감 후보**

- **gemini-2.5-flash-lite**: p50 1052ms로 가장 빠른 축, 단가 OpenRouter 카탈로그 기준 가장 낮음. 단 TP4 코칭에서 내부 분류명(`too_long`) 노출 사례 1건이 있어 시스템 프롬프트에 차단 지시 추가 후 사용 권장.
- **gpt-5.4-nano**: 토큰량은 mini와 비슷하면서 단가는 더 저렴. 단 TP4 원인선택지 도구 호출 실패는 mini와 동일.

**탈락**

- **solar-pro2**: 응답 길이가 매우 길고(글자 σ 180.1 — 모델 중 최악), **내부 분석 메타("추천 이유:", "[코칭 전략]", "[반응 예상]", "※")가 응답에 그대로 노출**. TP1 고학년 2회차 학생 이름 오류("서연아"), TP5에서 데이터에 없는 콘텐츠 환각("곤충 이름 맞추기", "강아지 3마리"). **현 상태로는 운영 부적합**.
- **solar-pro3** (motivator로는 탈락, helper로만 사용): TP1 고학년 7회차 학생 이름 오류("민준아" — 채원이여야), TP3·TP4 코칭에서 환각/placeholder("oo부터") 노출. 단 TP4 원인선택지 안정성은 1위라 helper 한정 사용 권장.

**시스템 프롬프트 개선 제안 (모든 모델 공통 약점)**

1. 학년별 글자수 한도 준수율이 7~26%로 매우 낮음 → 시스템 프롬프트에 명시적 글자 한도 지시 강화 필요.
2. "뽀롱쌤" 자기 호명 비율 0~24%로 낮음 → 페르소나 프롬프트에 "응답 시작 시 '뽀롱쌤이야' 같은 자기 호명을 포함하라"는 가이드 추가 검토.
3. 응답 안에 분석 메타가 노출되는 모델들이 있음 → "응답에 분석/메타 정보를 절대 포함하지 마라"는 강한 금지 지시 필요.

## 6. 한계 및 다음 단계

**이번 실험의 한계**

- 회차 N=10 → 통계 신뢰도 제한 (특히 변동이 큰 solar-pro2의 경우 더 큰 N 필요)
- 평가자 1인(Claude Code) → 평가자 간 분산 미측정. 사람 평가자의 추가 검증 권장
- 비용은 OpenRouter 단가표 별도 참조 필요
- 시스템 프롬프트가 Solar Pro 계열 기준으로 튜닝되어 있어 타 모델에 불리할 가능성

**확인된 핵심 발견**

- TP4 원인선택지(`send_causes` tool call) 호환성이 모델별 천차만별:
  - **GPT 계열 (mini·nano): 100% 실패** — `bind_tools`로 정의한 `send_causes`를 호출하지 않고 "어느 부분이 어려웠나요?"만 출력
  - solar-pro3·gemini-2.5-flash: 100% 성공
  - gemini-2.5-flash-lite·solar-pro2: 부분 성공 (text/choices 혼합)
- 학년 톤(글자수) 준수율이 모든 모델 공통 약점 (7~26%)
- 응답에 내부 메타("[코칭 전략]", `too_long` 같은 분류명, 학습어 목록)가 노출되는 사례가 solar 계열·gemini-flash-lite에서 발견 → 시스템 프롬프트에 명시 차단 지시 필요

**다음 단계 제안**

1. GPT 계열의 tool call 미작동 원인 디버깅 (`bind_tools` 호환성·strict mode 필요 여부)
2. 시스템 프롬프트에 글자수 한도·메타 노출 금지 강화 후 재실험
3. 페르소나 자기 호명("뽀롱쌤이야") 가이드 추가 후 재실험
4. 운영 단가 산정 (이 보고서 §2 토큰 평균 × OpenRouter 단가)
5. 추천 조합(motivator=gpt-5.4-mini · helper=solar-pro3) 으로 통합 실험
